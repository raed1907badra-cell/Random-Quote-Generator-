# Random-Quote-Generator-
Создать GUI-приложение «Random Quote Generator» с использованием random, сохранением истории и Git.
## Автор
[Бугай Александр Сергеевич 621гр]

## Описание приложения

Программа предоставляет удобный графический интерфейс для работы с цитатами:
- Генерация случайных цитат из предустановленного или пользовательского набора
- Добавление собственных цитат с автором и темой
- Просмотр истории всех сгенерированных цитат
- Фильтрация истории по автору и теме
- Автоматическое сохранение всех данных в JSON-файл

## Требования к системе

- Python 3.6 или выше
- Стандартная библиотека tkinter (входит в поставку Python)
- Операционная система: Windows, macOS, Linux
