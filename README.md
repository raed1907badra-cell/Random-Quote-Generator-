# Random Quote Generator (Генератор случайных цитат)

GUI-приложение для генерации случайных цитат с сохранением истории.

## Автор
[Бугай Александр Сергеевич]

## Описание
Приложение позволяет:
- Генерировать случайные цитаты из коллекции
- Добавлять свои цитаты
- Просматривать историю генераций
- Фильтровать историю по автору и теме
- Сохранять данные в JSON

## Требования
- Python 3.6 или выше
- Tkinter (входит в стандартную установку Python)
